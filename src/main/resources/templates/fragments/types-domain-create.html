Um domain é um tipo baseado em outro tipo (ex: text, integer) com uma regra de validação embutida. É útil para "travar" um conjunto de valores permitidos (como um enum) ou um formato (ex: e-mail), sem precisar repetir a mesma restrição em toda tabela que usar a coluna.

Basic info
  • Tipos comuns
Qualquer tipo válido do Postgres, incluindo tamanho/precisão (ex: varchar(100), numeric(10,2)). Não pode ser alterado depois de criado.
Constraints
Expressão regular que o valor precisa satisfazer, ex: ^[^@]+@[^@]+\.[^@]+$ para e-mail.
Para texto/data use aspas simples, ex: '2024-01-01'.

Use VALUE para se referir ao valor sendo validado.
